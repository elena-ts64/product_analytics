# Создание дерева метрик продукта
## Описание проекта
Декомпозиция продуктовых метрик от высокоуровневых бизнес-целей до операционных показателей для приложения по доставки продуктов.

Необходимо:
1) Определить NSM (North Star Metric)
2) Построить дерево метрик, состоящий из 3 уровней, в виде диаграммы
3) Добавить пояснения к выбранным метрикам

## Данные
Приложение для доставки продуктов "Самовывоз"

Мобильное приложение, позволяющее пользователям:
* Просматривать каталог продуктов из ближайших магазинов
* Формировать корзину и оформлять заказы
* Выбирать удобное время самовывоза из магазина
* Отслеживать статус заказа

## Инструменты
Draw.io

## Общий вывод
В качестве NSM была выбрана метрика "Конверсия в заказ", как основной показатель, влияющий на прибыль.
Для ветвей 2-го уровня были определены факторы, влияющие на NSM. 
Для ветвей 3-го уровня были определены составные элементы каждого фактора 2-го уровня.
Результат был оформлен в виде диаграммы при помощи инструмента draw.io с пояснением для каждой метрики.
